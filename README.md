# Pure Bilibili

Attention is all you need, not the recommendation.

适用于 B 站网页版的 Tampermonkey／Violentmonkey 脚本。首页直接替换为关注动态，过滤平台推荐、热搜和显式推广，同时保留全站搜索、个人记录与创作入口。

[安装 Pure Bilibili (Github)](https://raw.githubusercontent.com/squarezhong/pure-bilibili/main/pure-bilibili.user.js)


## 默认行为

| 区域 | 处理 |
| --- | --- |
| 首页／Logo | 主站首页跳转到 `https://t.bilibili.com/`；顶栏首页链接指向关注动态 |
| 网站顶栏 | 默认保留：首页／Logo、动态、消息、收藏、历史、创作中心、搜索、个人菜单；默认隐藏：番剧、直播大厅、游戏中心、会员购、漫画、赛事、下载客户端、大会员、投稿；独立直播顶栏的分区、充值和开播入口也默认隐藏。 |
| 关注动态 | 保留原生顺序、筛选、转发与联合创作；清除热搜、活动横幅和显式推广 |
| 搜索 | 保留所有作者、搜索关键词、历史、关键词联想、分类与排序；清除热词占位、热搜和显式广告 |
| 收藏／稍后再看／历史 | 保留全部记录和管理操作，仅清除推荐补位与推广 |
| 视频页 | 清除推荐栏、已识别的结束推荐和广告；关闭推荐栏「自动连播」 |
| 视频播放功能 | 保留自动开播、画质、字幕、弹幕、评论、分享、分 P、合集和主动播放队列 |
| UP 空间与关注管理 | 保留内容、搜索、分组、关注操作；清除平台推广和推荐关注模块 |
| 直播首页 | 保留「我的关注」，隐藏推荐、焦点播放器、分区导流、活动和人气榜 |
| 直播间 | 清除已识别的主播推荐和活动广告模块；保留直播、聊天和赛事赛程 |
| 创作后台 | 不注入脚本，不修改编辑器、上传或管理页面 |
